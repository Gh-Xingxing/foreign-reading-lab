# 外刊精读产品更新文档

## 反馈汇总

本轮反馈来自四个视角：雅思 6 冲 8 学员、资深 UI 设计师、雅思阅读教师、资深英语阅读爱好者。共同指向是：当前产品已经能完成外刊精读的基本闭环，但更像资料整理工具，还不够像一个“提分训练系统”。

## 关键问题

1. 学习路径不够强：用户进入文章后可以读、查、记，但缺少从略读到精读再到复盘的明确节奏。
2. 雅思拿分属性不足：当前偏文章理解和赏析，缺少题型、定位、同义替换、证据句等考试能力训练。
3. 划词操作距离较远：选中文本后需要移动到右侧面板，打断阅读流。
4. 积累不可复习：单词和句型能保存，但缺少状态管理，难以形成复习循环。
5. 笔记不够考试化：自由笔记适合记录想法，但不够约束用户输出段落功能、关键词、同义替换和错题原因。

## 本次更新目标

把产品从“外刊精读工具”升级为“外刊精读 + 雅思阅读训练工作台”。本次优先交付能直接提升使用路径和考试训练质量的改动。

## 已纳入本次修改

1. 新增训练页：提供 3 分钟略读、15 分钟精读、5 分钟复盘的训练流程和计时器。
2. 新增雅思题型训练：基于文章结构生成 Heading Matching、True/False/Not Given、Summary Completion、Multiple Choice、Evidence Hunt。
3. 新增选中文本浮动工具条：在正文中划词后可就地释义、翻译、朗读、高亮。
4. 强化积累复习：单词卡支持“新学、待复习、已掌握”状态切换。
5. 强化考试化笔记：提供雅思复盘模板，要求记录段落功能、关键词、同义替换、证据句、错因和输出句。
6. 强化导出：Markdown/PDF 归档加入训练流程和雅思题型内容。

## 后续建议

1. 加入用户答题记录、正确率和耗时统计。
2. 为在线 API 模式增加更严格的 JSON schema 校验，避免模型返回格式漂移。
3. 增加错题本，把错因按“定位失败、同义替换未识别、主旨误判、推断过度”归类。
4. 增加主题书架和阅读谱系，例如社会、科技、教育、经济、环境。
5. 增加英文 100 字 summary 和观点输出训练，并支持教师批改接口。
